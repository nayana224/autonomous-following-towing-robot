# 근거 자료

대회 발표와 시스템 구현에 참고한 원본 자료입니다. 원본 PDF는 수정하지 않고, 구현에 반영한 내용은 [아키텍처](../architecture.md), [안전 정책](../safety.md), [시연·운영 안내](../operation.md)에 요약합니다.

| 자료 | 용도 |
| --- | --- |
| `hardware/mdh250_inwheel_motor_manual.pdf` | In-wheel motor 제원 확인 |
| `hardware/mdrobot_mdt_dual_channel_bldc_driver_manual.pdf` | BLDC driver 연결·설정 확인 |
| `hardware/mdrobot_rs485_rs232_protocol.pdf` | Motor controller 통신 규약 확인 |
| `presentations/종합설계1 3차발표 - 메카뚜까.pdf` | 이전 발표 자료 보존 |

자료의 이름과 원본 파일은 그대로 유지합니다. 대회 제출 양식이나 평가 기준은 별도 공식 공고를 확인해야 하며, 이 저장소의 README를 공식 제출 문서로 간주하지 않습니다.
