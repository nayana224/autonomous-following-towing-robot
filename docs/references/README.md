# Reference Materials

This directory stores original source material that is useful as evidence but too large or too detailed for normal day-to-day repository navigation.

## Intended Contents

- hardware manuals
- driver and protocol references
- presentations
- other external evidence files that support implementation decisions

## Usage Rules

- Keep original reference files here rather than scattering them across packages.
- Summarize implementation-relevant findings into shared Markdown documents under `docs/`.
- Keep filenames stable when the files are externally sourced.
- Package-local notes may still exist, but shared conclusions should be captured in repository-level docs when they matter across packages.
