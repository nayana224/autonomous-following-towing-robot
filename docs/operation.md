# 운용 안내

이 문서는 Jetson Orin Nano에서 실제 로봇을 운용하는 순서를 설명합니다.

설치가 끝나지 않았다면 먼저 [설치 및 실행](setup.md)을 진행하세요. 안전 관련 세부 정책은 [안전 정책](safety.md)을 참고하세요.

## 1. 시작 전 확인

- 로봇 주변의 장애물을 정리합니다.
- 즉시 정지 또는 전원 차단이 가능한 운영자가 현장에 있어야 합니다.
- `/dev/ttyMotor`, `/dev/ttyLidar`가 연결되어 있는지 확인합니다.
- RealSense D435i가 연결되어 있는지 확인합니다.
- Fall Detection model이 `/models/fall_detection/yolov8n-pose.pt`에 준비되어 있어야 합니다.
- 견인 카트와 로봇의 연결 상태를 확인합니다.

## 2. 전체 시스템 실행

Jetson Host에서:

```bash
cd ~/260929_ws/src/autonomous-following-towing-robot
./scripts/docker_run_jetson.sh bash -lc   'ros2 launch aftr_gui operator_system.launch.py'
```

GUI가 실행되면 기본 시스템 준비 상태를 확인합니다.

## 3. 작업자 추종

경로를 저장하지 않고 추종만 수행할 경우:

1. `경로 저장`을 끕니다.
2. `작업자 추종`을 선택합니다.
3. 작업자가 로봇 전방에서 추종 대상이 되는지 확인합니다.
4. 종료 시 정지 기능을 사용합니다.

## 4. 경로 기록

1. `경로 저장`을 켭니다.
2. 작업자 추종을 시작합니다.
3. 로봇이 추종하는 동안 SLAM과 경로 기록이 함께 진행됩니다.
4. 작업이 끝나면 기록 종료를 선택합니다.
5. 경로, 지도 및 pose 저장 완료를 확인합니다.

주요 저장 위치:

```text
/data/paths/recorded_path.csv
/data/maps/mdbot_map.yaml
/data/maps/mdbot_map.pgm
/data/poses/last_pose.yaml
```

## 5. 정렬 및 위치 추정

필요한 경우 GUI의 수동 조작 기능으로 로봇을 정렬합니다.

정렬 완료 이후 시스템은 SLAM을 종료하고 Nav2/AMCL 기반 위치 추정을 준비합니다.

Localization이 준비되기 전에는 자율주행을 시작하지 않습니다.

## 6. 저장 경로 재생

`자율주행 준비 완료` 상태에서 허용된 방향을 선택합니다.

- **정방향 주행**: 출발점에서 도착점 방향으로 이동
- **복귀 주행**: 도착점에서 출발점 방향으로 이동

주행 중에는 GUI의 상태, 로봇 주변 환경 및 실제 이동 상태를 계속 확인합니다.

## 7. 운행 중단

운행 중 이상이 있거나 작업을 종료하려면 GUI의 중단 기능을 사용합니다.

중단 이후 시스템이 IDLE 또는 해당 안전 상태로 복귀했는지 확인합니다.

## 8. 낙상 및 안전 정지

낙상 감지 또는 detector heartbeat 손실 시 mode manager가 안전 정지 절차를 수행합니다.

안전 화면이 표시되면:

1. 로봇과 작업자의 상태를 직접 확인합니다.
2. 주변이 안전한지 확인합니다.
3. GUI의 안전 정지 해제 기능을 사용합니다.
4. 확인 대화상자에서 해제를 승인합니다.

이전 작업은 자동으로 재개되지 않습니다.

## 9. 종료

GUI와 ROS launch를 종료한 뒤 남아 있는 로봇 동작이 없는지 확인합니다. 이후 필요하면 Container와 로봇 전원을 순서대로 종료합니다.
